울림 메모 지원

메모를 시계 알람처럼 울리게 하는 iOS 앱 · iOS 26 이상

지원 · 개인정보 처리방침

어떤 앱인가

적어 둔 일을 정한 시간에 알람으로 울려 줍니다. 알림처럼 지나가지 않고, 다른 앱을 쓰는 중에도 화면을 덮습니다.

그리고 울린 뒤에도 남습니다. 끝냈는지, 미뤘는지, 몇 번 미뤘는지가 기록으로 쌓입니다. 지우지 않는 한 사라지지 않습니다.

주요 기능

  • 오늘 — 지난 일과 예정된 알림을 시간 순으로. 지금 시간이 선으로 표시됩니다.
  • 기록 — 한 달 달력에 날짜마다 결과가 기호로 남습니다(✓ 완료 · ↻ 미룸 · ⊘ 미완료).
  • 활동 기록 — 알림 하나에 일어난 일이 줄로 쌓입니다. 덮어쓰지 않습니다.
  • 나중에 — 알람 화면에서 누르면 설정한 만큼 뒤로 다시 울립니다.
  • 위젯과 Siri — 홈 화면 위젯과 제어 센터에서 바로 열 수 있고, Siri로도 열 수 있습니다.

알람이 울리지 않을 때

순서대로 확인해 주세요.

  1. 앱 안의 설정 → 권한에서 「알람」이 허용됨인지 봅니다. 거부됨이면 「iOS 설정 열기」를 눌러 켜 주세요.
  2. iOS 설정 → 울림 메모에서 알림이 켜져 있는지 봅니다.
  3. 알림 시간이 지나 있지 않은지 봅니다. 지난 시간으로는 저장되지 않습니다.
  4. 앱 안의 설정 → 소리 → 「알람 소리」가 꺼져 있으면 소리 없이 진동과 화면으로만 울립니다.
  5. 저전력 모드를 쓰고 계신다면 꺼 보고 다시 시험해 주세요.
진동은 끌 수 없습니다. iOS가 알람의 진동을 끄는 방법을 제공하지 않습니다. 앱의 「알람 소리」를 꺼도 진동은 납니다. 기기 전체의 진동을 끄려면 iOS 설정 → 손쉬운 사용 → 터치 → 진동을 꺼야 하며, 이 경우 긴급 재난문자 진동도 함께 꺼집니다.

「나중에」를 눌렀는데 다시 안 울릴 때

  • 다시 울리는 간격은 설정 → 새 알림 → 기본 시간을 따릅니다. 30분으로 되어 있으면 30분 뒤입니다.
  • 미룬 기록은 기록 탭에서 해당 알림을 눌러 확인할 수 있습니다. 「↻ 미룸」과 새로 맞춘 시간이 남습니다.

「기록을 열지 못했습니다」가 뜰 때

기록 파일을 읽지 못했을 때 나오는 안내입니다. 이때 앱은 원래 파일을 덮어쓰지 않습니다.

  • 원래 파일은 「울림-메모 깨짐 (날짜 시간).json」 같은 이름으로 앱 안에 그대로 남습니다. 안내 창에 그 이름이 표시됩니다.
  • 새 기록은 새 파일에 쌓이며, 남겨 둔 파일은 건드리지 않습니다.
  • 「원래 파일을 옮기지 못해 새 기록을 저장하지 않습니다」라고 나오면 기기 저장 공간이 부족한 경우입니다. 공간을 확보한 뒤 앱을 다시 열어 주세요.
  • 이 안내는 설정 → 기록에도 남습니다. 어떤 파일이 남았는지 나중에 다시 볼 수 있습니다.

이 안내를 보셨다면 문의해 주세요. 어떤 상황에서 생겼는지 알면 고칠 수 있습니다.

기록이 사라진 것 같을 때

  • 오늘 탭은 오늘·내일과 아직 안 끝난 지난 일만 보여 줍니다. 끝냈거나 미완료로 넘어간 지난 일은 기록 탭에 있습니다.
  • 설정 → 기록에서 「등록한 알림」과 「활동 기록」의 건수를 볼 수 있습니다. 숫자가 남아 있다면 기록은 있는 것입니다.
  • 「기록 전체 삭제」를 누르면 복구할 수 없습니다.

기록 내보내기

설정 → 기록 → 「기록 내보내기」를 누르면 기록 파일을 파일 앱, 메일 등으로 보낼 수 있습니다.

이 앱은 서버나 클라우드에 백업하지 않습니다. 기록을 오래 남기고 싶다면 가끔 내보내 두시는 것을 권합니다.
